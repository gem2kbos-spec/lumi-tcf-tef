# Lumi TCF · TEF AI Trainer

面向 TCF Tout Public 与 TEF 的自适应训练应用。两个考试共用能力档案，集中训练语法、词汇、阅读和表达。

默认备考路径是法国留学预签证 / DAP，当前产品聚焦语言结构、词汇、阅读和书面表达。

## 启动

```bash
cp .env.example .env
npm start
```

打开 `http://localhost:3000`。没有配置 API 密钥时，应用会自动使用内置题库，全部训练和错题功能仍然可用。

如需 AI 动态出题、右侧连续提问、举一反三与智能生词解释，在 `.env` 中填写 DeepSeek 密钥：

```dotenv
DEEPSEEK_API_KEY=你的密钥
DEEPSEEK_MODEL=deepseek-v4-flash
```

然后启动：

```bash
npm start
```

API 密钥仅由服务端读取，不能提交到 Git。项目优先使用 DeepSeek；如未配置 DeepSeek，也可用 `OPENAI_API_KEY` 作为备用。

## 账号、付费审核与运营后台

程序现在支持独立会员账号。每个学员的做题记录、生词本、错题本和知识整理都单独保存；未开通、已暂停或已到期的账号无法调用训练 API。

在服务器环境变量中配置：

```dotenv
ADMIN_EMAIL=你的管理员邮箱
ADMIN_PASSWORD=至少10位的随机强密码
PAYMENT_QR_URL=你的微信或支付宝收款码图片公网地址
```

管理员登录后，网页右上角会显示“管理后台”，可完成：付款订单确认或拒绝、单个用户开通 30 天、延期 30 天、暂停权限和取消权限。确认订单会按套餐天数自动延长；当前有效期未结束时，从原到期日继续顺延。

会员与学习数据默认保存在 `server/data`。本地服务器可直接持久保存；正式收费部署必须使用持久磁盘或数据库。Render 免费实例的本地文件会在重建时丢失，不能作为正式收费环境的数据存储。切换数据库前，可先用本地版完整验证收款与开通流程。

### Supabase 持久化

在 Supabase SQL Editor 执行 [`supabase/schema.sql`](supabase/schema.sql)，随后配置服务器专用环境变量：

```dotenv
SUPABASE_URL=https://你的项目.supabase.co
SUPABASE_SERVICE_ROLE_KEY=仅服务端使用的service_role密钥
```

密钥配置完成后运行 `npm run migrate:supabase`。脚本会迁移会员、订单、评论、AI用量以及每个用户的训练进度、生词本和知识整理，并在写入后重新读取验证。本地文件不会删除，会继续作为迁移前备份。浏览器端永远不会获得 `service_role` 密钥；数据库表启用 RLS 且不向匿名用户开放。

## 第一版范围

- TCF 风格的词汇与语法四选一练习
- 日常通知、邮件、行政信息、叙述、说明和观点文本阅读
- 两类考试的写作任务与口语情境专项
- TCF / TEF 考试中心和全部题型入口
- 连续单题随机训练：每题提交后立即显示正误与解析
- 最近题目短期去重，不再按固定题组结束
- 同题型共享题库，TCF / TEF 不重复维护相同考点
- 用户真题按原始顺序导入并单独统计完成进度
- 每题解析后的“举一反三”可生成同考点 AI 变式题
- 每题提供中文讲解与法语解析；阅读记录个性化错误原因
- 词汇语法错题附相关知识卡，举一反三支持自定义生成要求
- 可滚动题库浏览器：按来源、题型、A1–C2、完成状态和答案校准状态查看
- 长页面快捷导航；可直接跳转考试专项、训练记录、AI补缺、真题题库和做题区
- 593道清洗后真题：题干/文章/考点搜索、答案校准状态筛选、每次50题渐进加载和接近底部自动续载
- 两级考点题库：语法、词汇、阅读可继续按细分考点筛选，并统计全部机经的完成进度
- 六档能力层级（A1–C2）与1–10内部难度；题目按词汇、句法、文本和推断要求逐题评估，不再按题号机械分级
- Word 真题批量导入与对账：保留来源题号、原始顺序、答案校准状态和源文件异常报告
- 593 道清洗后真题全部可作答；重复、任务说明残缺、答案不唯一和缺少源材料的题已剔除
- 题库精修：保留可靠四选一题；可恢复的源文档错位已修正，无法可靠恢复的题已移出题库
- AI补缺训练室：覆盖缺口生成与高频薄弱考点强化
- 短期冲刺面板：今日建议题量、错题优先级和真题覆盖率
- 随题选词生词本：语境收藏、中文释义、法语用法、搭配和例句
- 可刷新的顶部精炼知识点，替代宣传式标语
- 独立考试蓝图约束 A2/B1 范围、篇幅、技能与材料类型
- A2 / B1 难度和每组题数选择
- DeepSeek Chat Completion + JSON 输出（支持 OpenAI 备用）
- 无密钥自动降级为精选本地题库
- 自动批改、法语解析、错题持久化
- 一键错题复习，答对后自动移出待复习列表
- 正确率、连续学习天数与薄弱知识点统计
- 数字键答题、Enter 切换下一题的快捷操作
- AI 请求失败时自动回退，不中断训练
- 服务端不向浏览器泄露答案
- 注册、登录、30天会话与登录限流
- 会员套餐、扫码付款申报与人工审核开通
- 管理后台按账号开通、延期、暂停或取消权限
- 每位学员的进度、生词与知识整理完全隔离
- 每个会员每日 AI 调用额度与剩余次数显示，防止单个账号异常消耗 API 费用
- 待审核状态自动刷新、重复订单拦截、后台用户搜索和即将到期提醒
- 每道题独立评论区：会员讨论、本人删除、管理员标识与管理、重复评论和每日数量限制

## 项目结构

```text
public/                 网页界面
server/index.js         HTTP 服务和 API
server/ai-generator.js  AI 出题与输出约束
server/question-bank.js 内置题库
server/question-taxonomy.js 题型与细分考点分类体系
scripts/import_word_banks.py Word 真题解析、分级与导入脚本
server/tcf-blueprint.js TCF 范围与出题约束
server/store.js         学习记录和统计
test/                   自动测试
```

## 真题分类

导入题目可以提供 `category` 使用明确的细分考点；没有提供时会根据 `type` 和 `skill` 自动归类。真题进度只统计 `user_imported` 来源，不与精选题或 AI 补充题混合。

当前导入结果及源文档缺项记录在 `server/imports/import-report.json`。源文件没有答案键或答案有歧义的题会完整展示，但在校准前不会开放作答，防止错误答案进入错题统计。
